## Select a project

Use the actual course directory. Read IDE/library versions from project configuration; old reports do not establish universal tool compatibility. Boards, licensed simulators, or course data may be required beyond cloning.

## Run and direct outputs

Inspect entry points for sound playback, device access, long training, and writes to the working directory. Use a separate working copy/output location while preserving resource-relative paths. Such side-effecting experiments were not automatically run in this maintenance.

## Current verification

Two SOH loader tests use synthetic Excel data without network training or historical weights. Historic accuracy, FPGA timing, course hardware, and PLECS dynamics were not revalidated.
