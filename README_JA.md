## 利用と保守

各科目の実ファイルに応じて MATLAB/Simulink、PLECS、Vivado、STM32CubeIDE、Python を選びます。一括ビルドコマンドはありません。データ、外部ライブラリ、実機条件は個別に確認します。旧参照の欠落は明示し、代替ファイルを捏造しません。

## 検証範囲

今回、旧ローカル参照・改名パスを修正し、概要の過大表現を訂正しました。確認済み IDE/ネイティブビルド中間ファイル 296 件を追跡対象から外し、全ローカル実体と Git 履歴を保持しました。SOH 入口のパス変数と無効入力を修正し、入力テスト 2 件が成功。再学習、科目全体のシミュレーション、書き込み、実験の再実施は行っていません。
