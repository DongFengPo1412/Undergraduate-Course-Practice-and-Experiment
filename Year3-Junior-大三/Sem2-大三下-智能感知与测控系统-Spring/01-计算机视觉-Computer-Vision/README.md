## Task Details & Code Descriptions

### Task 1: Image Restoration & Face Blending
- **File**: `Code/face_blend.py` & `Code/image_inpainting.py`
- **Methodology**:
  - **Inpainting**: Utilizes Fast Marching Method (FMM) (Telea's algorithm) to reconstruct defective pixel values along the boundary of scratches.
  - **Face Blending**: Detects face bounding box and midline using Haar Cascade Classifier. Constructs a feathering mask with Gaussian blur and performs Alpha Blending:
    $$\text{Result} = \text{Original} \odot M_{\text{smooth}} + \text{Cyborg} \odot (1 - M_{\text{smooth}})$$
- **Execution**:
  ```bash
  python Code/face_blend.py
  python Code/image_inpainting.py
  ```

### Task 2: Camera Calibration & Lens Undistortion
- **File**: `Code/camera_undistort.py`
- **Methodology**:
  - Simulates optical radial distortion (barrel distortion) on a black-and-white checkerboard pattern ($k_1 = -0.25$, $k_2 = 0.05$).
  - Solves backward pixel mapping and remapping using bilinear interpolation:
    $$x_{\text{distorted}} = x(1 + k_1 r^2 + k_2 r^4)$$
  - Demonstrates camera model matrix estimation and lens calibration parameters using OpenCV's `undistort`.
- **Execution**:
  ```bash
  python Code/camera_undistort.py
  ```

### Task 3: Panoramic Image Stitching & Bounding Bounding Box Crop
- **File**: `Code/image_stitching.py`
- **Methodology**:
  - Computes SIFT/ORB features, executes matching, and estimates homography matrix using RANSAC to eliminate outliers.
  - Warps images into a cylindrical coordinate space to prevent peripheral perspective stretch.
  - Fuses multi-perspective boundaries using multi-band progressive blending.
  - Searches for the maximum non-zero inner bounding box to automatically crop uneven black boundary regions.
- **Execution**:
  ```bash
  python Code/image_stitching.py
  ```
