## 使用与维护

先进入具体课程目录，按实际工程文件选择 MATLAB/Simulink、PLECS、Vivado、STM32CubeIDE 或 Python 环境；本库没有统一构建命令。需要数据、外部库或实体设备的实验应单独检查。缺失资源的旧链接已改为明确说明，不构造替代文件。
